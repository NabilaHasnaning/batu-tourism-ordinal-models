# batu-tourism-ordinal-models
This is the code for my thesis, which compares Ordinal Logistic Regression and Ordinal SVM (RBF) on SRS-transformed Likert data. It includes SMOTE for handling imbalance, GridSearchCV for tuning, and a train/test evaluation using balanced accuracy, recall, and other class-based metrics. It also provides an interpretation via odds ratios and SHAP.
